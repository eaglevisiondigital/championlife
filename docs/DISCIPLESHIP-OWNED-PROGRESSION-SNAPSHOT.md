# Owned progression snapshot — source only

The earlier review adapter accepted an `owned_worksheet_transaction_v1` answer receipt only when a trusted repository supplied its learner/session/enrollment wrapper. This forward migration supplies that missing answer-side repository from the actual database. It does not supply the outstanding playback ledger or completion transaction.

`public.owned_progression_snapshot(p_lesson)` calls its private counterpart, which reuses unchanged `private.owned_worksheet_transaction(p_lesson,null,null)`. That transaction authenticates and locks the current verified user/session, acquires the existing worksheet mutation mutex, and locks the course/enrollment/version. Those locks persist through the outer transaction. The snapshot reads the exact matching enrollment and opaque version and checks session expiry again before returning. Existing legacy answer/enrollment triggers retain their ordering. No caller learner/session/enrollment ID is accepted and no answer/progress/enrollment is written.

The return projects the existing answer gate's discriminator and nested receipt, plus matching learner/session/enrollment and UUID version. It contains no raw answer or private numeric sequence value. It always reports `playbackStatus: observer_unconfigured`, `canComplete:false`, `canCommit:false`. Only the existing twenty-question cloud worksheets1–4 are supported. Lessons5–13 remain device notes and videos11–13 remain unavailable.

A returned JSON object is historical evidence, never a transferable capability. The locks end with the database transaction. It cannot be passed through an external observer call and then claimed still serialized. A future completion writer must reload/validate the current snapshot inside its own transaction while serializing all additional media, observer-policy and replay sources. No observer registry, live ledger port or completion writer is installed here.

Validation: `node tools/discipleship-progression/progression-snapshot.database.mjs` runs36 checks against PGlite using the actual migrations and evidence evaluator. It covers current Auth restrictions, foreign/revoked/expired session boundaries, no raw answers/counter, exact ACLs, legacy edits, enrollment replacement and the actual opaque-answer shape without watch credit. Existing293 Node tests PASS. Independent read-only review adds18 passing SQL checks. `TEST_NATIVE_PG=1` additionally exercises a session deletion and a legacy answer update blocked by the snapshot transaction; CI runs that mode. Native concurrency was NOT run locally because of the existing Mac IPC limit. No hosted/Auth/provider or browser acceptance is claimed.

No changes to frozen King Kind PR57, public courses, SDK, existing migrations or giving. Exact source review and CI must pass before publication; installation, genuine provider/session acceptance and release require separate approvals. Stop/rollback means leave this uninstalled or stop consuming it; do not drop prior worksheet metadata, remove legacy triggers or delete evidence.
